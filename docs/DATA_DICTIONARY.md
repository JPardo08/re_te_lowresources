# Data dictionary

Public data areas for Paper-1 reproducibility. Source-specific bibliographic columns from Scopus/WoS exports are numerous; they are summarized collectively unless they participate in filtering or joins.

## Legend

| Kind | Meaning |
|------|---------|
| Frozen | Committed input; not regenerated by reproduction scripts |
| Generated | Produced by `reproduce_*.py` from frozen inputs |
| Manual / preserved | Human decisions stored in Excel; exported deterministically |

---

## `sources/`

### `sources/scopus/`

| Item | Detail |
|------|--------|
| Content | Per-query frozen Scopus CSV exports: `q*/{A,B}/scopus.csv` |
| Kind | Frozen |
| Producer | Historical Scopus search exports |
| Downstream | `scopus_core.csv` / `scopus_unique.csv` |

Core Paper-1 queries: `q1`, `q2`, `q3`, `q4`, `q16`, `q17`. Other query folders may exist for exploratory IE/generation searches and are excluded from the core funnel.

### `sources/web_of_science/`

| Item | Detail |
|------|--------|
| Content | Per-query frozen WoS Excel exports: `q*/{A,B}/savedrecs.xls` |
| Kind | Frozen |
| Producer | Historical Web of Science search exports |
| Downstream | `wos_core.csv` / `wos_unique.csv` |

Same core query families as Scopus.

### `sources/others/`

Auxiliary / background research PDFs (methods surveys, related datasets, exploratory reading). **Not** inputs to the automatic Selection funnel. Subject to third-party copyright (see `NOTICE`). Retained for scientific context in the public research package.

## Key columns

| Column | Where | Meaning |
|--------|-------|---------|
| `query` | Platform + Selection | Query family id (`q1`, …) |
| `search_engine` | Selection | `Scopus` or `Web of Science` |
| `pipeline_view` | Selection automatic CSVs | `historical` or `corrected` (never mixed) |
| `title` / `Article Title` | Platform / Selection | Bibliographic title (canonical Selection field: `title`) |
| `doi` | Many stages | Document DOI when present |
| `eid` | Scopus / Selection | Scopus EID; WoS UT mapped to `eid` in corrected alignment |
| `language of original document` | Selection | English filter field |
| `authors`, `author full names`, `author(s) id` | Selection | Required for the author-metadata / “proceedings” filter |
| `paper_id` | Manual final / final corpus | Stable short study id (e.g. `guo`) |
| `choosen` | Manual study selection | Numeric chosen flag from workbook |
| `choosen_state` | Manual study selection | `Yes` / `No` / `Doubt` |
| `notes` | Manual study selection | Preserved screening notes |
| `in_final_corpus` | `final_selection.csv` | Whether a Yes record appears in the 42-study corpus |
| `solution_name` | Final / Yes audit | Method/solution label when present in Data extraction |

### Source-specific metadata

Scopus and WoS exports retain vendor bibliographic fields (affiliations, keywords, venue, citation counts, identifiers, etc.). Reproduction preserves these fields where practical; Selection filtering depends only on the fields listed above plus the documented schema map (see `src/re_te_lowresources/selection.py`).
